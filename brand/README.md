# Samite brand files

Copy into `apps/web/public/brand/` at M0. Don't redraw the mark; use these files.

| File | Use |
|---|---|
| `samite-mark-cream.svg` | The mark (the eye in a spiky sun), cream `#F2EFE8`, transparent. Nav, footer, anywhere on black |
| `samite-mark-ink.svg` | The same in ink `#0A0A0A`, for cream backgrounds |
| `favicon.svg`, `favicon-32.png`, `apple-touch-icon-180.png`, `icon-512.png` | Favicon set: black rounded square, cream mark |
| `samite-og-1200x630.png` | Open Graph / X card (regenerate from `design/prototype/og.html` at 1200×630 if the copy changes) |
| `samite-avatar-original-400.png` | X avatar |
| `samite-logo-original-1000.png` | The logo, 1000 px |
| `samite-logo-white-transparent.png` | The logo in cream on transparent |
| `samite-banner-v2-1500x500.png`, `samite-banner-v2-2172x724.png` | X banner |
| `samite-banner-clean.png` | The banner art without text: the source of the press photos (`design/prototype/assets/`) |

The wordmark is set in type, not stored as a file: `SAMITE` in Montserrat 800 italic, uppercase, letter-spacing .03em, next to the mark (mark height ≈ 1.02 × the font size, gap ≈ .22 × the font size).
